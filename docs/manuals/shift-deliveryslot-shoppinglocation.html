1. Shift (Shift Kerja)

Mendefinisikan shift kerja untuk penjadwalan karyawan. Contoh: Pagi (06:00–14:00), Siang (14:00–22:00), Malam (22:00–06:00). Akses: sidebar Master Data → Shift atau /shifts.

edit shifts✅❌❌
delete shifts✅❌❌

Field Form — Shift

Kode✅ YaKode singkat. Contoh: P, S, M. Unik, maks 10 karakter.

💡 Shift digunakan di modul Employee Setiap karyawan bisa dikaitkan dengan satu shift. Data shift hanya referensi — tidak ada logika absensi atau penjadwalan otomatis.

2. Delivery Slot (Slot Pengiriman)

Mendefinisikan slot waktu pengiriman untuk menjadwalkan kedatangan supplier. Slot dikaitkan ke supplier dan ditampilkan di Delivery Monitor (TV display). Akses: sidebar Master Data → Jadwal Slot Pengiriman atau /delivery-slots.

Permission — Delivery Slot

PermissionSuperadminLeaderOperator
view delivery slots✅✅❌
edit delivery slots✅❌❌
⚠️ Modul ini hanya bisa VIEW + EDIT Tidak ada fitur tambah (create) dan hapus (delete) untuk Delivery Slot. Data slot biasanya sudah di-seed langsung ke database. Kamu hanya bisa mengubah label atau waktu slot yang sudah ada.

Field Form — Delivery Slot (Edit only)

FieldKeterangan
Slot NumberNomor urut slot. Format: C-01, C-02. Read-only — tidak bisa diubah.
Time StartJam mulai slot. Format: HH:MM:SS.
Time EndJam selesai slot.
LabelNama deskriptif. Contoh: Pagi (06:00-08:00).
Screenshot: Halaman daftar Delivery Slot — tabel: Slot Number, Time Start, Time End, Label, Aksi (Edit saja)
🔗 Kaitan dengan modul lain
  • Supplier Edit — kamu bisa mencentang slot mana yang tersedia untuk supplier tertentu.
  • Delivery Monitor — TV display yang menampilkan jadwal supplier berdasarkan slot. Supplier dengan slot tertentu akan muncul di monitor sesuai waktunya.

3. Shopping Location (Lokasi Tujuan)

Mendaftarkan lokasi mitra/tujuan pengiriman barang. Digunakan saat membuat transaksi Shopping (pengiriman keluar). Contoh: Toko Mitra A, Gudang Cabang B. Akses: sidebar Master Data → Lokasi Tujuan atau /shopping-locations.

Catatan: Tidak ada Import/Export

Modul Shopping Location tidak memiliki fitur import/export Excel. Semua data harus diinput manual satu per satu melalui form tambah.

4. Troubleshooting

🚫 Tidak bisa tambah/hapus Delivery Slot

Penyebab: Delivery Slot memang didesain hanya untuk view & edit. Tidak ada permission create atau delete.

Solusi: Jika perlu menambah slot baru, harus dilakukan via database seeder atau migration oleh developer.

📺 Supplier tidak muncul di Delivery Monitor

Penyebab: Supplier belum dikaitkan dengan delivery slot apapun.

Solusi: Edit supplier, centang slot pengiriman yang tersedia untuk supplier tersebut.

🕐 Jam shift tidak sesuai urutan

Penyebab: Shift ditampilkan sesuai urutan di database (berdasarkan id), bukan berdasarkan jam.

Solusi: Tidak ada sorting khusus. Beri nama/kode yang jelas agar mudah diidentifikasi di dropdown.

🗑️ Tidak bisa hapus Shopping Location

Penyebab: Lokasi sudah dipakai di transaksi Shopping.

Solusi: Hapus atau pindahkan transaksi yang terkait terlebih dahulu.

🔘 Tombol Edit/Hapus tidak muncul

Penyebab: Permission tidak dimiliki. Semua modul ini memerlukan permission spesifik untuk edit/delete.

Solusi: Hubungi superadmin. Cek permission yang dibutuhkan di section masing-masing modul.
