Permission

Screenshot: Halaman Supplier Performance — metric cards (Total Cycles, On-Time Rate, Incomplete), filter Supplier + Date, tabel ringkasan per supplier, detail incomplete items

Memahami Metrik Performa

Total Cycles
Jumlah cycle completed
On-Time Rate
% cycle selesai tepat waktu
Incomplete
Item dengan shortfall

Definisi Metrik

MetrikDefinisiCara baca
On-Time Delivery Rate Persentase cycle yang diselesaikan (completed) tepat atau sebelum delivery date yang dijanjikan Rate tinggi (>80%) = supplier handal. Rate rendah (<50%) = supplier sering terlambat. Pertimbangkan penjadwalan ulang.
Incomplete Items Item yang quantity diterima < quantity di dokumen (shortfall) Item incomplete tinggi = supplier sering kirim kurang. Tindak lanjuti dengan klaim atau penyesuaian order.
Total Cycles Jumlah total cycle completed untuk supplier tersebut Konteks — supplier dengan 100 cycle dan 90% on-time lebih baik dari supplier dengan 5 cycle dan 100%.
💡 Filter & Analisis Gunakan filter Supplier + Rentang Tanggal untuk analisis spesifik. Contoh: "Bagaimana performa Supplier X dalam 3 bulan terakhir?" — pilih supplier, set date range 3 bulan, lihat metriknya.

4. Delivery Monitor (TV Display)

Layar monitor publik (TV) yang menampilkan jadwal kedatangan supplier secara real-time. Cocok dipasang di area bongkar muat gudang. Tidak memerlukan login.

Permission — Publik!

URLAksesKeterangan
/delivery-monitor🔓 Publik (tanpa login)Halaman utama — grid supplier card dengan status real-time
/delivery-monitor/suppliers/{id}/ledger🔓 PublikAPI JSON — riwayat cycle supplier (dipakai oleh panel detail)
/tv-dashboard🔓 PublikDashboard TV alternatif
Screenshot: Delivery Monitor — grid kartu supplier dengan slot waktu, status badge, progress bar penerimaan

Penggunaan TV Display

  1. Setup di gudang

    Pasang TV/layar besar di area bongkar muat. Buka browser, akses http://[SERVER_IP]:8090/delivery-monitor (atau port production kamu).

  2. Supplier muncul otomatis

    Supplier yang sudah dikaitkan dengan Delivery Slot (via Edit Supplier) akan muncul di grid sesuai slot waktunya.

  3. Kartu Supplier

    Setiap kartu menampilkan: nama supplier, kode, slot waktu, dan status pengiriman hari ini.

  4. Panel Detail

    Klik kartu supplier untuk melihat detail: riwayat cycle, item yang diterima, status terkini.

  5. Update otomatis

    Data ter-update real-time via websocket setiap ada penerimaan. Sebagai jaring pengaman, monitor juga auto-refresh tiap 15 detik — walau websocket gagal (mis. jaringan TV berbeda), data tetap masuk maksimal 15 detik tanpa refresh manual.

⚠️ Delivery Monitor tidak butuh login Karena ini akses publik, informasi yang ditampilkan terbatas pada data operasional (nama supplier, slot, status). Tidak ada data sensitif seperti harga, kontrak, atau data karyawan.

Troubleshooting

🚫 Tidak bisa akses halaman Report

Penyebab: Role Operator tidak punya akses ke modul Report.

Solusi: Hanya Leader & Superadmin. Minta upgrade role jika diperlukan.

📊 Data report kosong / tidak sesuai

Penyebab: Filter terlalu ketat, atau memang belum ada data transaksi.

Solusi: Kosongkan filter (pilih "All" di dropdown), atau perlebar date range.

📺 TV Monitor tidak muncul / blank

Penyebab: URL salah, server tidak terjangkau, atau browser tidak support.

Solusi: Cek URL — harus /delivery-monitor. Pastikan TV terhubung ke jaringan yang sama dengan server. Coba refresh halaman.

🏭 Supplier tidak muncul di Delivery Monitor

Penyebab: Supplier belum dikaitkan dengan Delivery Slot apapun.

Solusi: Edit supplier → centang slot pengiriman yang diinginkan. Supplier akan muncul di monitor sesuai slot.

📈 On-Time Rate tidak akurat

Penyebab: Delivery date di cycle mungkin tidak diisi dengan benar, atau cycle belum completed.

Solusi: Pastikan delivery date diisi saat membuat cycle. Hanya cycle completed yang dihitung di metrik.
