1. Overview

Modul Supplier Management adalah pusat pengelolaan data pemasok (supplier) di sistem WMS MAW. Setiap barang yang masuk ke gudang dikaitkan dengan supplier tertentu, sehingga data supplier menjadi fondasi untuk proses receiving, pelacakan stok, dan laporan performa.

Fitur Modul Supplier

FiturDeskripsi
📋 Daftar SupplierMelihat semua supplier dengan pencarian dan pagination
➕ Tambah SupplierMendaftarkan supplier baru beserta alamat utama
🔍 Detail SupplierMelihat info lengkap, kode, kontak, dan daftar alamat
✏️ Edit SupplierMengubah data supplier & mengatur jadwal delivery slot
🗑️ Hapus SupplierMenghapus supplier yang tidak lagi digunakan
📥 Import ExcelImport banyak supplier sekaligus dari file .xlsx / .csv
📤 Export ExcelExport semua data supplier ke file Excel
💡 Kode Supplier Otomatis Saat membuat supplier baru, kode akan di-generate otomatis dari singkatan nama (3 huruf pertama kata signifikan). Prefix seperti "PT", "CV", "UD" akan dilewati. Contoh: PT. Adi Jaya Makmur → AJM. Jika kode sudah dipakai, sistem otomatis menambahkan angka (AJM1, AJM2, dst). Kamu juga bisa mengisi kode secara manual.

2. Akses & Permission

WMS MAW menggunakan sistem Role-Based Access Control (RBAC). Tidak semua user bisa mengakses semua fitur supplier. Berikut permission yang mengatur akses modul ini:

Permission Matrix — Supplier

PermissionFungsiSuperadminLeaderOperator
view suppliers Melihat daftar & detail supplier, export ✅✅✅
create suppliers Menambah supplier baru, import Excel ✅❌❌
edit suppliers Mengedit data & delivery slot supplier ✅❌❌
delete suppliers Menghapus supplier ✅❌❌
⚠️ Tombol tidak muncul? Jika kamu tidak melihat tombol Tambah Supplier, Edit, atau Hapus, artinya role kamu tidak memiliki permission tersebut. Hubungi administrator sistem untuk penyesuaian role.

3. Melihat Daftar Supplier

Halaman daftar supplier bisa diakses melalui sidebar menu Master Data → Suppliers, atau langsung ke URL /suppliers.

Screenshot: Halaman daftar supplier — tabel dengan kolom Kode, Nama, Kontak Person, Email, Telepon, dan Aksi

Fitur di Halaman Daftar

ElemenFungsi

4. Menambah Supplier Baru

🧑‍💼 Permission dibutuhkan: create suppliers
  1. Buka form tambah

    Klik tombol Tambah Supplier di halaman daftar supplier, atau langsung ke URL /suppliers/create.

  2. Isi data supplier

    Field Form — Data Supplier

    FieldWajibKeterangan
    Kode / SingkatanTidakMaks 10 karakter. Otomatis di-generate jika dikosongkan.
    Nama✅ YaNama lengkap supplier. Harus unik.
    Kontak PersonTidakNama orang yang bisa dihubungi.
    Email✅ YaEmail supplier. Harus unik & format valid.
    TeleponTidakNomor telepon, maks 20 karakter.
  3. Isi alamat utama

    Field Form — Alamat

    FieldWajibKeterangan
    Jalan✅ YaNama jalan & nomor.
    Kota✅ YaNama kota, maks 100 karakter.
    Provinsi✅ YaNama provinsi, maks 100 karakter.
    Kode Pos✅ YaKode pos, maks 20 karakter.
    Negara✅ YaDefault: Indonesia.
  4. Simpan

    Klik tombol Simpan. Sistem akan memvalidasi input. Jika ada error, field yang bermasalah akan ditandai merah.

  5. Redirect ke detail

    Setelah berhasil, kamu otomatis diarahkan ke halaman detail supplier yang baru dibuat, dengan pesan sukses "Supplier created successfully.".

6. Mengedit Supplier

🧑‍💼 Permission dibutuhkan: edit suppliers
  1. Buka form edit

    Klik ikon ✏️ Edit di tabel daftar supplier, atau tombol Edit di halaman detail supplier. Kamu juga bisa langsung ke URL /suppliers/{id}/edit.

  2. Ubah data yang diperlukan

    Form edit sama dengan form tambah — semua field bisa diubah. Aturan validasi tetap berlaku (nama unik, email unik, dll).

  3. Atur Delivery Slot (opsional)

    Di bagian bawah form edit, terdapat daftar checkbox delivery slot. Centang slot waktu pengiriman yang tersedia untuk supplier ini. Supplier hanya bisa mengirim di slot yang dipilih.

    💡 Delivery Slot Slot pengiriman digunakan oleh modul Delivery Monitor (TV display) untuk menjadwalkan kedatangan supplier. Supplier dengan slot yang sudah diatur akan muncul di jadwal monitor.
  4. Simpan perubahan

    Klik Simpan. Kamu akan diarahkan kembali ke halaman detail supplier dengan pesan sukses.

7. Menghapus Supplier

🧑‍💼 Permission dibutuhkan: delete suppliers

⚠️ Peringatan: Menghapus supplier bersifat permanen. Pastikan tidak ada data produk, cycle, atau transaksi yang masih terkait dengan supplier ini. Supplier yang masih digunakan oleh data lain mungkin gagal dihapus karena constraint database.
  1. Di halaman daftar supplier, klik ikon 🗑️ Hapus pada baris supplier yang ingin dihapus.
  2. Sistem akan menampilkan dialog konfirmasi: "Yakin ingin menghapus supplier ini?"
  3. Klik OK untuk menghapus, atau Batal untuk membatalkan.
  4. Setelah berhasil, halaman akan refresh dan supplier hilang dari daftar.

8. Import Supplier (Excel)

🧑‍💼 Permission dibutuhkan: create suppliers

Fitur import memungkinkan kamu menambahkan banyak supplier sekaligus dari file Excel (.xlsx atau .csv).

  1. Download template

    Klik tombol 📥 Import/Export di toolbar, lalu pilih Download Template. File Excel template berisi header kolom yang sesuai dengan format impor.

  2. Isi data di template

    Kolom Template Import

    KolomWajibContoh
    codeTidakAJM
    name✅ YaPT Adi Jaya Makmur
    contact_personTidakBudi Santoso
    email✅ Yabudi@adijaya.co.id
    phoneTidak021-5551234
    street✅ YaJl. Industri Raya No. 12
    city✅ YaJakarta
    state✅ YaDKI Jakarta
    postal_code✅ Ya12345
    country✅ YaIndonesia
  3. Upload & Preview

    Klik 📥 Import/Export → Import. Pilih file Excel yang sudah diisi. Sistem akan menampilkan modal preview yang menunjukkan data yang akan diimpor.

    Screenshot: Import Modal — preview data sebelum import
  4. Konfirmasi Import

    Periksa data di preview. Jika ada error (misal: nama duplikat, email tidak valid), baris bermasalah akan ditandai. Klik Import untuk memproses data yang valid.

  5. Selesai

    Setelah import berhasil, halaman akan refresh dan supplier baru muncul di daftar.

⚠️ Catatan Import
  • Supplier dengan nama yang sama dengan data yang sudah ada akan di-skip (tidak diduplikasi).
  • Setiap supplier yang diimpor otomatis dibuatkan alamat utama dari data alamat di file Excel.
  • Jika ada baris yang gagal, baris lain tetap diproses. Pesan error akan ditampilkan.

9. Export Supplier (Excel)

🧑‍💼 Permission dibutuhkan: view suppliers

Export semua data supplier ke file Excel dengan sekali klik.

  1. Di halaman daftar supplier, klik tombol 📥 Import/Export di toolbar.
  2. Pilih Export.
  3. Browser akan otomatis mengunduh file suppliers-export.xlsx.

Data yang di-export

File export berisi kolom: Nama, Kontak Person, Email, Telepon, Jalan, Kota, Provinsi, Kode Pos, Negara (9 kolom).

Data diambil dari seluruh supplier yang ada di database, tanpa filter pencarian.

10. Troubleshooting

🚫 Error 403 — Forbidden

Penyebab: Role kamu tidak memiliki permission untuk aksi yang dicoba (tambah/edit/hapus).

Solusi: Hubungi superadmin untuk mengecek role & permission kamu. Superadmin bisa mengelola permission di menu Setup → Roles atau Setup → Permissions.

🔘 Tombol tidak muncul

Penyebab: Sama seperti di atas — permission tidak dimiliki. Selain itu, pastikan kamu sudah logout dan login ulang setelah role diubah, karena permission di-cache di session.

📛 Nama supplier sudah digunakan

Penyebab: Validasi unik — nama supplier tidak boleh sama dengan yang sudah ada.

Solusi: Gunakan nama yang berbeda, atau periksa apakah supplier tersebut sudah terdaftar sebelumnya.

📧 Email tidak valid / sudah terdaftar

Penyebab: Format email salah, atau email sudah dipakai supplier lain.

Solusi: Perbaiki format email (harus mengandung @ dan domain valid), atau gunakan email lain.

📥 Import gagal / data tidak muncul

Penyebab: Format file salah, atau kolom wajib kosong.

Solusi:
• Pastikan menggunakan template resmi (download dari tombol Download Template).
• Pastikan kolom name, email, street, city, state, postal_code, country tidak kosong.
• File harus berekstensi .xlsx atau .csv.
• Cek pesan error di modal preview — baris yang error akan ditandai.

🗑️ Tidak bisa menghapus supplier

Penyebab: Supplier masih terkait dengan data produk, cycle penerimaan, atau transaksi lain. Database menolak penghapusan untuk menjaga integritas data.

Solusi: Hapus atau pindahkan data yang terkait terlebih dahulu (produk, cycle, dll), lalu coba hapus supplier kembali.

🔄 Setelah ganti role, permission belum update

Penyebab: Session user masih menyimpan role & permission lama. Sistem tidak otomatis me-refresh session saat role diubah.

Solusi:
• Logout dan login ulang.
• Jika masih bermasalah, minta superadmin menjalankan php artisan optimize:clear di server.
