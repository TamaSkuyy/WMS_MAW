1. Import/Export Guide

Hampir semua modul Master Data mendukung import dari Excel dan export ke Excel. Pola operasinya seragam di semua modul. Halaman ini menjelaskan alur umum yang berlaku untuk semua modul.

Alur Import

  1. Download Template

    Di halaman daftar modul, klik 📥 Import/Export → Download Template. File Excel template berisi header kolom yang sesuai format import modul tersebut.

  2. Isi data di template

    Buka file Excel, isi data sesuai kolom. Kolom wajib tidak boleh kosong. Simpan sebagai .xlsx atau .csv.

  3. Upload & Preview

    Klik Import/Export → Import. Pilih file. Modal preview muncul menampilkan data yang akan diimpor.

    Screenshot: Import Modal — tabel preview dengan baris valid & error
  4. Review error

    Baris yang bermasalah (nama duplikat, field wajib kosong, format salah) akan ditandai. Baris ini akan di-skip saat import.

  5. Konfirmasi Import

    Klik Import. Halaman refresh dan data baru muncul di daftar.

Alur Export

  1. Di halaman daftar modul, klik 📥 Import/Export → Export.
  2. Browser otomatis mengunduh file Excel ([module]-export.xlsx).
  3. Export mengambil seluruh data — tidak terpengaruh filter atau pencarian yang sedang aktif (kecuali modul Report: export mengikuti filter).

Tips & Troubleshooting Import

✅ Best Practices

  • Selalu gunakan template resmi — jangan buat file dari nol.
  • Isi data referensi (supplier, kategori, model) dulu SEBELUM import produk.
  • Nama referensi (supplier, model, kategori) bersifat case-sensitive — tulis persis seperti di sistem.
  • Import dalam batch kecil (max 100-200 baris) untuk menghindari timeout.
  • Test import dengan 2-3 baris dulu sebelum import massal.

Notifikasi

Sistem punya fitur notifikasi real-time via Laravel Reverb (WebSocket). Icon lonceng 🔔 di header. Notifikasi muncul untuk event seperti:

  • Cycle selesai diterima
  • Shopping selesai dikirim
  • Notifikasi sistem / test broadcast

Klik icon lonceng untuk melihat daftar notifikasi. Klik Tandai semua sudah dibaca untuk menghapus badge unread.

Deploy ke Production

🚀 Quick Update (30-90 detik)

Untuk perubahan kode PHP + React/Vite:

./deploy-production.sh --update --with-assets

Ini otomatis: maintenance mode → copy kode → build assets → migrate → clear cache → reload workers → maintenance off.

🔄 Smart Rebuild (2-3 menit)

Untuk perubahan composer.json atau package.json:

./deploy-production.sh --rebuild

💥 Force Rebuild (10 menit)

Untuk perubahan Dockerfile atau infrastruktur:

./deploy-production.sh --build
⚠️ Setelah seeder, selalu reload worker Jika kamu menjalankan seeder di production (misal WmsRoleSeeder), Octane worker menyimpan permission di memory. Jalankan ini setelah seeder: 
docker compose -p wms-wma-prod -f docker-compose.prod.yml exec app php artisan optimize:clear
docker compose -p wms-wma-prod -f docker-compose.prod.yml exec app php artisan config:cache
docker compose -p wms-wma-prod -f docker-compose.prod.yml exec app php artisan route:cache
docker compose -p wms-wma-prod -f docker-compose.prod.yml restart app

Backup Database & Storage

Backup Storage Volume

# Backup storage (uploads, logs, framework) ke ./backups/
./deploy-production.sh --backup-storage

# Cek isi volume
./deploy-production.sh --check-storage

Backup Database (manual)

# Export database dari container MySQL
docker compose -p wms-wma-prod -f docker-compose.prod.yml exec mysql \
  mysqldump -u wms_user -p wms_wma > backup_$(date +%Y%m%d).sql
💡 Spatie Backup Package Sistem sudah terpasang spatie/laravel-backup. Backup otomatis bisa dijadwalkan via BACKUP_SCHEDULE_ENABLED=true di .env.prod. File backup tersimpan di storage/app/backups/.

Maintenance Mode

Aktifkan Maintenance Mode

docker compose -p wms-wma-prod -f docker-compose.prod.yml exec app php artisan down --retry=5 --render="errors::503"

Pengunjung akan melihat halaman 503. Deploy script otomatis mengaktifkan ini.

Nonaktifkan Maintenance Mode

docker compose -p wms-wma-prod -f docker-compose.prod.yml exec app php artisan up
