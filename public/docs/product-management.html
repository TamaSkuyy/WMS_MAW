1. Overview

Modul Product Management adalah pusat data seluruh barang di gudang. Setiap produk punya part number unik, terkait dengan satu supplier, satu model kendaraan, satu kategori, dan bisa disimpan di rak default. Modul ini menjadi fondasi untuk transaksi receiving, shopping, dan pelacakan stok.

Fitur Modul Product

FiturDeskripsi
📋 Daftar ProdukMelihat semua produk dengan filter kategori & supplier, pencarian, dan indikator status stok
➕ Tambah ProdukMendaftarkan produk baru dengan spesifikasi lengkap
🔍 Detail ProdukMelihat info lengkap produk + data supplier terkait
✏️ Edit ProdukMengubah data & spesifikasi produk
🗑️ Hapus ProdukMenghapus produk yang tidak lagi digunakan
📊 Status StokIndikator otomatis: Normal, Low, Out, Over berdasarkan min/max stok
📥 Import ExcelImport banyak produk sekaligus dari file .xlsx / .csv
📤 Export ExcelExport semua data produk ke file Excel
🔗 Relasi Produk Produk terhubung dengan beberapa modul lain:
• Supplier — pemasok produk ini (wajib)
• Model Kendaraan — model kendaraan yang menggunakan produk ini (wajib)
• Kategori Produk — pengelompokan jenis produk (wajib)
• Rak Default — lokasi penyimpanan utama (opsional)

Pastikan data referensi (Supplier, Vehicle Model, Product Category, Rack) sudah diisi sebelum menambah produk.

4. Menambah Produk Baru

🧑‍💼 Permission dibutuhkan: create products
  1. Buka form tambah

    Klik tombol Tambah Produk di halaman daftar produk, atau langsung ke URL /products/create.

  2. Isi data produk

    Field Form — Data Produk

    FieldTipeWajibKeterangan
    Part NumberText✅ YaKode unik produk, maks 50 karakter. Tidak boleh duplikat.
    NamaText✅ YaNama lengkap produk, maks 255 karakter.
    Model KendaraanDropdown✅ YaPilih dari daftar model kendaraan yang sudah terdaftar.
    SupplierDropdown✅ YaPilih pemasok produk ini.
    KategoriDropdown✅ YaPilih kategori produk (contoh: Body Parts, Electrical, dsb).
    SatuanText✅ YaUnit satuan: pcs, set, box, unit, dll. Maks 20 karakter.
    DeskripsiTextareaTidakKeterangan tambahan, maks 1000 karakter.
    Status AktifToggleTidakON = produk aktif. OFF = produk nonaktif (tidak muncul di transaksi). Default: ON.
    Rak DefaultDropdownTidakRak penyimpanan utama. Saat receiving, sistem otomatis mengarahkan ke rak ini.
    Min StokNumberTidakBatas minimum stok. Di bawah ini → status Low.
    Max StokNumberTidakBatas maksimum stok. Di atas ini → status Over.
  3. Simpan

    Klik tombol Simpan. Sistem akan memvalidasi input — pastikan part number belum digunakan dan semua field wajib terisi.

  4. Redirect ke halaman produk

    Setelah berhasil, kamu diarahkan ke halaman daftar produk dengan pesan sukses "Product created successfully.".

6. Mengedit Produk

🧑‍💼 Permission dibutuhkan: edit products
  1. Buka form edit

    Klik ikon ✏️ Edit di tabel daftar produk, atau tombol Edit di halaman detail.

  2. Ubah data yang diperlukan

    Semua field bisa diubah, termasuk part number. Aturan validasi tetap berlaku (part number unik, dll).

  3. Atur Min/Max Stok

    Field Min Stok dan Max Stok menentukan indikator status stok. Lihat section 10 — Status Stok untuk detailnya.

  4. Simpan perubahan

    Klik Simpan. Kamu akan diarahkan kembali ke halaman detail produk.

7. Menghapus Produk

🧑‍💼 Permission dibutuhkan: delete products

⚠️ Peringatan: Produk yang sudah memiliki data stok, tercatat di cycle penerimaan, atau terkait transaksi shopping tidak bisa dihapus. Database menolak penghapusan untuk menjaga integritas data transaksi.
  1. Di halaman daftar produk, klik ikon 🗑️ Hapus pada baris produk yang ingin dihapus.
  2. Sistem menampilkan dialog konfirmasi.
  3. Klik OK untuk menghapus, atau Batal untuk membatalkan.
  4. Produk yang berhasil dihapus akan hilang dari daftar.

⚠️ Catatan Penting Import
  • Part number duplikat akan menyebabkan baris tersebut dilewati (skip).
  • Supplier, model kendaraan, dan kategori harus sudah terdaftar di sistem sebelum diimpor.
  • Nama supplier & kategori bersifat case-sensitive — pastikan penulisannya persis sama.

10. Memahami Status Stok

Setiap produk memiliki indikator status stok yang dihitung otomatis berdasarkan total stok di semua rak dibandingkan dengan min stok dan max stok yang ditetapkan.

4 Status Stok

StatusBadgeKondisiTindakan
Normal NORMAL Stok antara min dan max (atau min/max tidak diatur) Tidak ada tindakan khusus
Low LOW Stok di bawah min stok, tapi masih di atas 0 Segera lakukan receiving / restock
Out OUT Stok = 0, padahal min stok sudah diatur Segera order ke supplier
Over OVER Stok di atas max stok Pertimbangkan mengurangi order / memindahkan stok
💡 Tips mengatur Min/Max Stok
  • Min Stok idealnya sedikit di atas lead time order — cukup untuk menutupi kebutuhan selama supplier memproses order baru.
  • Max Stok adalah kapasitas maksimum yang masuk akal — hindari menumpuk stok berlebihan yang memakan ruang rak.
  • Jika min/max stok tidak diatur (kosong), status akan selalu Normal.

11. Troubleshooting

🚫 Error 403 — Forbidden

Penyebab: Role kamu tidak memiliki permission untuk aksi produk (tambah/edit/hapus).

Solusi: Hubungi superadmin. Untuk role Operator, modul produk bersifat read-only.

🔘 Tombol Tambah/Edit/Hapus tidak muncul

Penyebab: Permission tidak dimiliki, atau session masih menyimpan role lama.

Solusi: Logout dan login ulang setelah role diubah.

📛 Part number sudah digunakan

Penyebab: Part number harus unik — tidak boleh ada dua produk dengan part number sama.

Solusi: Gunakan format part number yang unik, misalnya dengan prefix supplier atau kategori: BRK-001, ELC-012.

📥 Import gagal — supplier/kategori/model tidak ditemukan

Penyebab: Data referensi (supplier, model kendaraan, kategori) yang tertulis di file Excel belum terdaftar di sistem, atau penulisannya tidak persis sama (case-sensitive).

Solusi:
• Daftarkan supplier/model/kategori terlebih dahulu.
• Pastikan penulisan nama persis sama (termasuk huruf besar/kecil, spasi, tanda baca).

📊 Status stok tidak sesuai ekspektasi

Penyebab: Min/max stok belum diatur atau nilainya tidak sesuai.

Solusi: Edit produk dan sesuaikan nilai Min Stok dan Max Stok.

🗑️ Tidak bisa menghapus produk

Penyebab: Produk masih memiliki data stok di rak, tercatat di cycle penerimaan, atau terkait transaksi shopping.

Solusi: Nonaktifkan produk (set is_active = false) daripada menghapusnya. Produk nonaktif tidak muncul di form transaksi baru.
