1. Overview

Modul Employee Management menghubungkan data karyawan dengan sistem login & RBAC. Setiap karyawan bisa punya akun user, dan role user otomatis mengikuti jabatan (Job Position) yang dipegang.

Fitur Utama

FiturDeskripsi
📋 Data KaryawanNama, NIK, jabatan, departemen, lokasi kerja, shift, kontak, status
🔗 Auto UserBisa langsung buat akun login saat tambah karyawan (opsional)
🔑 Generate UserBuatkan akun login untuk karyawan yang sudah ada — kirim link reset password
🎖️ Auto RoleRole user otomatis mengikuti role_name di Job Position
📜 Audit TrailCatatan siapa yang membuat & terakhir mengupdate data karyawan
📥 Import ExcelImport banyak karyawan sekaligus
📤 Export ExcelExport seluruh data karyawan

3. Konsep: Employee → User → Role

Ini adalah alur paling penting untuk dipahami:

👤 Employee → 🎖️ Job Position → 🔑 Role (Spatie) → 🔐 User Login → ✅ Permission

Penjelasan Alur

LangkahKeterangan
1. Employee dibuatData karyawan diisi: nama, NIK, jabatan, departemen, dll.
2. Job Position punya role_nameSaat memilih jabatan, sistem lihat apakah jabatan itu punya role (contoh: leader, operator).
3. User dibuat (opsional)Bisa langsung saat tambah karyawan (centang Auto Create User) atau nanti via tombol Generate User.
4. Role otomatis terpasangUser login langsung dapat role sesuai jabatan. Tidak perlu setting manual.
5. Permission mengikuti roleRole leader dapat permission leader, role operator dapat permission operator.
⚠️ Role superadmin tidak auto-assign Untuk keamanan, role superadmin tidak bisa diberikan otomatis via Job Position. Harus diberikan manual melalui menu Setup → Users atau Setup → Roles.

5. Menambah Karyawan Baru

🧑‍💼 Permission: create employees
  1. Buka form tambah

    Klik Tambah Karyawan atau ke /employees/create.

  2. Isi data karyawan

    Field Form — Karyawan

    FieldWajibKeterangan
    Nama✅ YaNama lengkap karyawan.
    NIKTidakNomor Induk Karyawan — opsional tapi disarankan diisi.
    Jabatan✅ YaDropdown dari Job Position. Menentukan role user nanti.
    Departemen✅ YaDropdown dari Department.
    Lokasi Kerja✅ YaDropdown dari Work Location.
    ShiftTidakDropdown dari Shift.
    TeleponTidakNomor kontak.
    EmailTidak*Email untuk login. Wajib jika centang Auto Create User.
    StatusTidakAktif / Nonaktif. Default: Aktif.
    Auto Create UserTidakCentang untuk langsung buat akun login. Email wajib diisi. Password acak akan dikirim.
  3. Auto Create User

    Jika dicentang, sistem otomatis membuat user login dengan:

    • Email = email yang diisi di form
    • Password = random (dikirim via email/password reset)
    • Role = otomatis dari role_name di Job Position

    Jika tidak dicentang, kamu bisa membuat user nanti via tombol Generate User.

  4. Simpan — karyawan baru muncul di daftar.

7. Mengedit Karyawan

🧑‍💼 Permission: edit employees
  1. Klik ✏️ Edit di tabel daftar atau halaman detail.
  2. Ubah data yang diperlukan.
  3. Jika mengubah Jabatan dan jabatan baru punya role berbeda, role user akan otomatis di-sync ulang. Karyawan harus logout & login ulang agar role baru berlaku.
  4. Klik Simpan.
⚠️ Ganti jabatan = ganti role Saat jabatan karyawan diubah, sistem otomatis meng-update role user-nya dan menghapus semua session aktif. Karyawan akan dipaksa login ulang dengan role baru.

8. Generate User Login

🧑‍💼 Permission: edit employees

Fitur ini membuatkan akun login untuk karyawan yang sudah ada tapi belum punya user.

  1. Di halaman daftar karyawan, klik tombol 🔑 Generate User pada baris karyawan (hanya muncul jika karyawan belum punya user).
  2. Sistem akan:
    • Membuat user baru dengan email dari data karyawan
    • Password random
    • Role otomatis dari Job Position
    • Mengirim link reset password ke email karyawan (jika mailer dikonfigurasi)
  3. Karyawan bisa login dengan email tersebut dan melakukan reset password.
⚠️ Email wajib diisi Generate User akan gagal jika field Email di data karyawan kosong. Edit karyawan dan isi email terlebih dahulu.

9. Menghapus Karyawan

🧑‍💼 Permission: delete employees

⚠️ Perhatian: Menghapus karyawan tidak otomatis menghapus user login-nya. User tetap bisa login meski data karyawan sudah dihapus. Nonaktifkan user secara terpisah jika diperlukan.
  1. Klik 🗑️ Hapus pada baris karyawan.
  2. Konfirmasi dialog.

10. Import & Export

Import Karyawan

Permission: create employees

Download template, isi data, upload via Import/Export → Import. Kolom template: nama, nik, jabatan, departemen, lokasi_kerja, shift, telepon, email, status.

Export Karyawan

Permission: view employees

Klik Import/Export → Export. File employees-export.xlsx otomatis terunduh.

11. Troubleshooting

🚫 Error 403

Penyebab: Hanya Superadmin yang bisa kelola karyawan. Leader hanya read-only.

🔑 Generate User gagal

Penyebab: Email karyawan kosong, atau email sudah dipakai user lain.

Solusi: Isi email unik di data karyawan, lalu coba generate lagi.

🔄 Role tidak berubah setelah edit jabatan

Penyebab: Job Position yang baru tidak punya role_name.

Solusi: Edit Job Position dan pilih role di dropdown Role Name.

📧 Karyawan tidak terima email reset password

Penyebab: Mailer belum dikonfigurasi (production pakai MAIL_MAILER=log).

Solusi: Konfigurasi SMTP di .env.prod, atau superadmin bisa reset password manual via Setup → Users.

👻 User tetap bisa login setelah karyawan dihapus

Penyebab: User dan Employee adalah entitas terpisah. Hapus karyawan tidak menghapus user.

Solusi: Nonaktifkan atau hapus user secara manual di Setup → Users.
